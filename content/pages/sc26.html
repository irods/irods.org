Supercomputing 2026

We will be holding meetings and giving talks in the RENCI booth (#1655) at SC26 in Chicago:

2026 iRODS Update


Come hear about this year's 5.1.0 release. Logical Quotas. FIPS Compatibility. TLS during setup. New 'irods' authentication scheme. Many security and performance updates.

iRODS System Tray App


This new system tray application provides a hands-free fire-and-forget method to get lab-generated instrument data ingested into the scientific data pipeline as soon as possible. Pure python. Runs on Windows and MacOS.

iRODS S3 API Update


iRODS can present as S3. Providing a multi-bucket, and multi-user S3 service, the iRODS S3 API now offers public buckets and authentication via keypair or token. Host or instance-based authentication is also possible through the same plugin interface.
